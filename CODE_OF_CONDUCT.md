# Code of conduct

This project follows the [Contributor Covenant, version
3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).

## In short

Be kind and be direct. Disagreement about code is the point of a code
review; contempt for a person is not. Assume the other person read the
same documentation you did and reached a different conclusion for a
reason.

Unacceptable behaviour includes harassment, personal or political
attacks, publishing anyone's private information, and sustained
disruption of discussions.

## Scope

This applies in the issue tracker, in pull requests, in commit messages
and in any other space where someone is representing the project.

## Reporting

Report a concern through a [private security
advisory](https://github.com/mmedum/google-sheets-mcp/security/advisories/new),
which is the one private channel this repository has. It is the wrong
name for the purpose and the right level of privacy; say in the first
line that it is a conduct report rather than a vulnerability.

Reports are read by the maintainers. Expect an acknowledgement within a
few days. What you send stays with the people handling it.

**Do not include anything from a real spreadsheet** in a report — the
same rule the rest of this repository runs on. If a screenshot is the
evidence, crop or redact it.

## Enforcement

The maintainers will do what the Covenant's enforcement ladder describes:
a private correction, a warning, a temporary ban, or a permanent ban,
proportionate to what happened and to whether it continued after being
raised. A maintainer who breaks these rules is subject to them.
